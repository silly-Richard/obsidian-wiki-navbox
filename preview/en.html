Wiki Navbox

A Wikipedia-style collapsible navigation table for Obsidian: View · Edit, two-level groups, wiki links, light and dark themes, and remembered collapse state.

Light theme Click [Collapse] or the View · Edit actions
Dark theme Adapts to Obsidian theme variables

Rendered by the real ```wiki-navbox code path, with no network requests. In Obsidian, internal links use the native link system.
